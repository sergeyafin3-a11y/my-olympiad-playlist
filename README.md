# My Olympiad Playlist

Тренажёр для подготовки к заключительному этапу ВсОШ по английскому языку.
Задания, ключи и аудио — официальные материалы олимпиады из открытого архива
Центра педагогического мастерства: https://всош.цпм.рф

## Обновление
После любой правки в `js/` или `data/` — `python3 tools/bump_version.py`:
он ставит скриптам в `index.html` метку версии, чтобы браузер не смешивал
новую страницу со старыми файлами из кэша. Тесты: `python3 -m unittest discover -s tests`.
