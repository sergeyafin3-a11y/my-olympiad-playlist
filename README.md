# Lexicon Legend

Тренажёр по английскому: подготовка к ВсОШ (полный вариант финала), олимпиадная лексика, грамматика A1–B2 и личный словарик.
Задания, ключи и аудио — официальные материалы олимпиады из открытого архива
Центра педагогического мастерства: https://всош.цпм.рф

## Обновление
После любой правки в `js/` или `data/` — `python3 tools/bump_version.py`:
он ставит скриптам в `index.html` метку версии, чтобы браузер не смешивал
новую страницу со старыми файлами из кэша.
Он же пишет версию страницы в `version.json`: открытая старая страница
сверяется с ним и сама перезагружается на новую. Тесты: `python3 -m unittest discover -s tests`.
